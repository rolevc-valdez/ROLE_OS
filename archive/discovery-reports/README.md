# Archived Discovery Reports

## What these are

Reports produced by Role OS's Discovery Engine CLI (`python -m app.discovery audit --root <path> --output <path>`, `dashboard/app/discovery/__main__.py`) — a deliberate, manual, read-only audit tool. It reuses the exact same Discovery Engine the FastAPI app uses for its normal `1 - IA PROJECTS` scans, but lets a person point it at *any* folder and get a JSON + Markdown report: per-folder classification (Software Project / Mixed Project / Non-project), health scores, move-risk findings (e.g. hardcoded absolute paths), and archive/rename/move recommendations.

This is genuinely unique information — a snapshot of what a completely different, non-default folder looked like on that date — not reproducible from Role OS's canonical databases, Git, or any other doc, and not automatically regenerated by anything.

**Files:** `documents_audit.json` (structured), `documents_audit.md` (human-readable). Both preserved byte-for-byte (SHA256 verified identical before/after archiving) from their original location, `var/discovery_reports/documents/`.

## Why archived, not left in `var/`

Role OS 2.0's convention (established across Phase 1) is that `var/` holds ephemeral, regenerable, git-ignored runtime state — never anything a person would mind losing. This report doesn't fit that: it's a one-off, non-regenerated-by-default export with real informational value. Rather than leave it ambiguously sitting in a directory everything else treats as disposable, it's moved here (git-tracked, like `archive/legacy-dashboard/`) so it survives deliberately, not by accident.
